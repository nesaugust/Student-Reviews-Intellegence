# Student-Reviews-Intellegence

## Power BI Dashboard

### Overview

Review volume, course ratings, and AI-generated feedback themes.

![Student Feedback Overview](images/overview.png)

### Feedback Evidence

Filter comments by course, theme, and sentiment, then inspect
the supporting quotations and full reviews.

![Feedback Evidence](images/evidence.png)

### Model Evaluation

Evaluation of the TF-IDF and Logistic Regression baseline
against LLM-generated pseudo-labels.

![Model Evaluation](images/model.png)

These metrics measure agreement with LLM-generated labels,
not accuracy against independent human annotations.
